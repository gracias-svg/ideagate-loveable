# IDEAGATE — PHASE 1

## FOUNDATION

### Visual DNA & Design System

Before starting:

Read the attached IDEAGATE-LOVABLE-MASTER-SPECIFICATION.md completely.

Treat it as the source of truth.

This prompt only builds the visual foundation.

Do not build product screens.

Do not build backend functionality.

Do not create placeholder dashboards.

Do not invent new product features.

Your goal is to establish the visual DNA that every future screen will inherit.

------------------------------------------------

OBJECTIVE

Create a premium mid-2026 SaaS design system suitable for an AI-native Product Operating System.

The experience should feel calm, editorial, intelligent, and highly refined.

Think in the quality range of products such as:

• Linear

• Notion

• Cursor

• Raycast

• Vercel

• Craft

Do not imitate any of these products.

Develop a unique visual language for IdeaGate.
